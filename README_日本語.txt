MY TASKS - PWA タスク管理アプリ

■ 内容
- タスクの追加、完了/未完了切り替え、削除
- 優先度（高・中・低）
- すべて/未完了/完了済みの絞り込み
- 達成率表示
- localStorageによる端末内保存
- Service Workerによるオフライン起動

■ 重要：スマホにインストールするには
PWAはHTTPSで配信する必要があります。ZIPをスマホに保存しただけでは、
ホーム画面アプリとしてインストールできません。

■ 公開方法（例：GitHub Pages）
1. PCでGitHubにログインし、新しいPublicリポジトリを作成
2. ZIPを解凍し、中のファイル一式をリポジトリ直下にアップロード
3. Settings → Pages → Deploy from a branch を選択
4. Branch: main / Folder: /(root) を選択して Save
5. 発行された https://...github.io/... のURLをAndroid Chromeで開く
6. Chromeのメニューから「アプリをインストール」または
   「ホーム画面に追加」を選ぶ

■ データについて
タスクはブラウザのlocalStorageに保存されます。
サーバーには送信されません。同じ端末・同じブラウザ内で利用してください。
Chromeのサイトデータを消去したり、アプリデータを削除したりすると、
保存したタスクも消える場合があります。大切なデータは別途バックアップしてください。

■ オフラインについて
最初にオンラインでアプリを開き、Service Workerのインストールが完了してから
オフライン利用できます。初回アクセス前のオフライン起動はできません。

■ フォントについて
標準ではシステムフォントで動作します。オンライン時にGoogle Fontsを読み込む
設定がCSSにあります。完全オフライン時は端末の日本語システムフォントに
フォールバックします。
